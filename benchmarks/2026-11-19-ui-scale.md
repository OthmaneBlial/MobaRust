## Session tree at scale

Generated with the preview-only `?previewScale=N` parameter, which adds N SSH sessions spread over 8 regions × 40 racks. Each value is one run.

| Sessions | Change | First paint | Search "host-12" | Clear search | Tab click | Heap |
|---|---|---|---|---|---|---|
| 2,000 | before | 500 ms | 59 ms | 328 ms | 108 ms | 77 MB |
| 2,000 | after | 268 ms | 51 ms | 150 ms | 4 ms | 49 MB |
| 5,000 | before | 952 ms | 121 ms | 880 ms | 284 ms | 80 MB |
| 5,000 | after | 520 ms | 90 ms | 363 ms | 6 ms | 100 MB |

**Fix:** the filtered list and the session tree are memoized, and row actions go through a ref. Per-folder SSH counts are computed in one pass instead of folders × sessions. Folder groups use `content-visibility: auto`.

### Virtualized tree (same day)

The remote tree is now a flat list of fixed-height items (folder 28 px, session 43 px). Only the rows near the visible part of `.session-list` are rendered, with 600 px of overscan. The search query uses `useDeferredValue`, so typing never waits on the list.

| Sessions | First paint | Search (4 queries) | Tab click | Scroll to end | DOM nodes | Heap |
|---|---|---|---|---|---|---|
| 9 | 152 ms | 9–19 ms | 14 ms | 33 ms | 663 | 6.2 MB |
| 500 | 200 ms | 8–19 ms | 14 ms | 32 ms | 1,102 | 7.6 MB |
| 2,000 | 172 ms | 13–19 ms | 14 ms | 32 ms | 1,111 | 10.0 MB |
| 5,000 | 188 ms | 8–24 ms | 13 ms | 30 ms | 1,111 | 12.7 MB |

The interaction timings include the probe's own one or two animation-frame waits (about 16 ms each), so 10–30 ms is the measurement floor, not app work.

Geometry checks at the top, middle and end of the 5,000-session list found 0 overlaps, 0 gaps and no overflowing rows. Browser-preview checks confirmed collapse/expand, open, edit, "Open all" counts, the picker and search.

**Trade-off:** off-screen rows are not in the DOM, so browser find-in-page and Tab only reach rows near the viewport. The sidebar search covers every session.

## Synthetic Rust harness (`cargo xtask benchmark`, same day)

- Raw output was not committed, following `benchmarks/README.md`.
