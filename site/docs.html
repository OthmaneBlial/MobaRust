Install the preview

The Mac build is version 0.1.31. The Windows and Linux builds are version 0.1.12. All of them are previews without publisher signing. GitHub's automatic source archives are not installers.

macOS · Apple SiliconDMG 0.1.31Drag MobaRust to Applications macOS · IntelDMG 0.1.31Drag MobaRust to Applications Windows · x64Installer 0.1.12Installs WebView2 if needed Ubuntu / Debian · x64DEB 0.1.12For apt-based desktops Other Linux · x64AppImage 0.1.12WebKitGTK 4.1 and FUSE may be needed Release notesSHA-256 filesChecksums and install notes

macOS may block the first launch because the app is ad hoc signed and not notarized, and Windows may show SmartScreen. Use your system's per-app review flow only if you trust the download, and never turn off system security globally. Checksums detect a corrupted download; they do not prove who published it.

The group opener, MobaXterm import and the new interface are on the main branch and are not in these downloads yet. Build from source to use them today.

Import from MobaXterm

In MobaXterm on Windows, export your sessions to a file. In MobaRust, choose Import MobaXterm sessions in the session list and pick the file. It works on macOS, Linux and Windows.

ItemWhat happens
Files.mxtsessions, single-session .moba files and MobaXterm.ini, in Windows-1252, UTF-8 or UTF-16, with Windows or Unix line endings.
ImportedSSH and SFTP bookmarks with name, nested folder, host, port, username, login command, comment and SSH gateways (as jump hosts).
KeysA path such as C:\Users\you\.ssh\id_ed25519 becomes ~/.ssh/id_ed25519 when that file exists. Otherwise the SSH agent is used and the session notes say which file to copy. PuTTY .ppk keys get a puttygen conversion hint.
Never readPasswords and every credential section of the file.
Not importedX11, proxy, terminal, font and colour settings. RDP, VNC, Telnet and serial bookmarks are listed as skipped.
DuplicatesBefore anything is saved, a preview lets you add, replace or skip each duplicate. The import is written in one step, so a failure leaves your sessions unchanged.

The field layout follows a public community study of the MobaXterm format, not vendor documentation. It is tested with Windows-style exports, including a real connection to a local OpenSSH server through an imported gateway, but not with a file written by MobaXterm itself. Please report any file that does not import.

Security boundaries

  • SSH host-key verification refuses unknown keys until you choose a trust source.
  • Session settings are kept apart from passwords and private keys. Native code resolves saved credential references, and interactive SSH answers are never saved in profiles.
  • Secrets are kept out of profile data, logs and helper process arguments.
  • The interface has no unrestricted shell command bridge.
  • Multiline paste asks first. Multi-exec shows its targets and has an emergency stop.
  • Network jobs have bounded input and output, timeouts, cancellation and cleanup.
  • Repository tests use throwaway state and loopback servers. They never read personal SSH files or connect to real hosts.

Read the threat model, the safe testing policy and the dependency audit.

Known limits

  • Installers are built and checked locally. They have no publisher signature, and the Mac packages are ad hoc signed and not notarized.
  • The 0.1.31 Mac preview can keep a busy error in Files after a successful refresh. A fix is in the source; a corrected installer is pending. Receipt.
  • A tunnel forwarding attempt with an uncertain outcome closes its SSH connection and ends other work on it. Tunnel receipt.
  • A successful build does not prove clean-install behavior or compatibility with every SSH server.
  • RDP and VNC are experiments. RDP is not packaged, and VNC over TCP has no transport encryption.
  • Windows and Linux hardware, WSL, clipboard and serial devices need testing on those systems.

Build from source

You need Rust 1.90 or newer, Node.js 22, pnpm 10 and the Tauri prerequisites for your system.

git clone https://github.com/OthmaneBlial/MobaRust.git
cd MobaRust
pnpm install --dir apps/desktop --frozen-lockfile
cargo xtask check
pnpm --dir apps/desktop tauri dev

Copy only puts the commands on your clipboard. Nothing runs.

The checks use isolated home folders, throwaway fixtures and loopback networking. They do not need your SSH files, Keychain, SSH agent, real hosts or hardware. ./tools/local-protocol-lab.sh runs every real-protocol suite on this machine and checks that nothing is left running.

Evidence

Every claim on this site points to a receipt in the repository.

  • Test matrix: what is tested against real local OpenSSH, what uses fixtures, and what is still open.
  • Native macOS benchmark: launch time, idle CPU and memory, and clean shutdown of the release build on an Apple M2.

Report bugs in GitHub Issues with your system, architecture and steps. Remove credentials, hostnames, IP addresses and private details first.
