Unsigned means unsigned. Windows may show SmartScreen. macOS may block first launch because the app is not Developer ID signed or notarized. Follow the OS's per-app review flow only if you trust the download. Never disable system security globally.

Checksum files help detect download corruption. They do not verify who published an installer.

03 / Security

Clear edges, deliberate actions.

  • SSH host-key verification rejects unknown keys until the operator chooses a trust source.
  • Session configuration is separate from passwords and private keys. Native code resolves credentials when a protocol needs them.
  • Secrets are excluded from ordinary profile data, logs, and helper process arguments.
  • There is no unrestricted shell command bridge from the renderer.
  • Multiline shell paste is confirmed. Multi-exec shows selected targets and an emergency disable path.
  • Network jobs use bounded input/output, timeouts, cancellation, and cleanup.
  • Repository tests use disposable state and loopback fixtures. They do not inspect personal SSH files or connect to real hosts.

Read the full threat model, safe testing policy, and dependency audit.

04 / Known limits

Preview means work remains.

  • The release workflow builds installers on native GitHub runners and checks version, assets, checksums, and binary startup.
  • The installers are unsigned. Publisher signing and macOS notarization are not available in this release.
  • Build success does not prove full GUI clean-install behavior or remote-server interoperability.
  • RDP/VNC remain experiments. RDP is not packaged; VNC remote TCP has no transport encryption.
  • Windows/Linux hardware, WSL, clipboard, serial devices, and broader platform behavior need target-environment evidence.

MobaRust is independent and is not affiliated with Mobatek or MobaXterm. There is no claim of feature-for-feature parity. See the roadmap for open gates.

05 / Build from source

Run the local path.

Requirements: Rust 1.88 or newer, Node.js 22, pnpm, and the Tauri prerequisites for your operating system.

git clone https://github.com/OthmaneBlial/MobaRust.git
cd MobaRust
pnpm install --dir apps/desktop
cargo xtask check
cargo tauri dev --manifest-path apps/desktop/src-tauri/Cargo.toml

Copies commands only. Nothing is executed.

The validation path uses isolated home directories, disposable fixtures, and loopback networking. It does not need personal SSH files, Keychain, GitHub keys, SSH agents, real hosts, or attached hardware.

06 / Evidence

Check the current receipts.

Quality checks run locally with cargo xtask check; GitHub Actions is reserved for release installer builds.

The v0.1.11 release page carries native-runner installers and SHA-256 files after all four target jobs succeed. These receipts do not replace signing, clean installation, or hardware evidence.

Report bugs with the operating system, architecture, and reproduction steps in GitHub Issues. Remove credentials, hostnames, IP addresses, and private connection details first.
