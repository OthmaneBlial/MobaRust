# MobaRust v0.1.27 — Explicit Legacy Text Open

**Free, open-source MobaXterm alternative built with Rust**

This Mac preview adds an explicit encoding choice when opening remote text files. Windows/Linux downloads remain v0.1.12.

## What changed

- **Open legacy text deliberately:** choose **Open text as → Windows-1252** in the SFTP browser before Edit. UTF-8 remains the strict default; invalid UTF-8 is refused without altering the remote file. There is no encoding guessing or lossy fallback.
- **Open and Save choices stay clear:** the browser choice controls decoding; **Save encoding** in the editor controls output. Existing bounded reads, revision conflict checks, temporary-save recovery and permissions remain in use.
- **Local regression coverage:** a desktop command-queue check preserves the selected encoding and path validation; the OpenSSH encoding fixture verifies explicit reopen content, revision, size and mode before conversion.
