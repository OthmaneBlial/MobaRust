# MobaRust v0.1.25 — Safer Remote Editing & Transfers

**Free, open-source MobaXterm alternative built with Rust**

This Mac preview brings the editor, transfer and SFTP lifecycle corrections added since v0.1.24 into both Mac installers. Windows/Linux downloads remain v0.1.12.

## Changes since v0.1.24

- **Remote editor:** original-byte revision checks survive encoding conversion;
  exclusive mode-0600 parts refuse occupied files/links. Acknowledged saves return
  the written buffer and revision, with a visible warning if backup cleanup fails.
- **Transfers:** exact type checks guard upload destinations and download sources.
  SFTP/SCP parts use exclusive private creation; Unix download parts request mode
  0600. Cancellation and copy failures await file shutdown before promotion or
  cleanup, and SDK statuses retain their redacted application classification.
- **Remote mutations:** Delete unlinks final symlinks, including trailing-slash
  selections. Rename, Delete, mkdir and chmod require named final entries;
  chmod refuses live final symlinks and unknown types without opening contents.
- **SFTP lifecycle:** unsigned offsets are bounded and failed end-seeks recover.
  Shutdown drains failed WRITE replies, awaits one CLOSE, retires other handle
  operations and avoids duplicate close requests after cancellation or retry.
- **Benchmark reports:** timing probes expose raw samples, medians and ranges;
  contended CPU samples remain explicit rather than being labelled idle.

## Package validation

Both locally built DMGs passed disk-image verification, read-only mounted layout checks, strict ad hoc signature verification, matching app/VNC architectures, isolated CLI version checks, bundled LICENSE/NOTICE byte comparison and exact seven-file package inventory. No private lab state or environment metadata was present. All owned mounts were detached. SHA-256 manifests match the staged installer bytes. All four published files were downloaded anonymously over HTTPS with HTTP 200 responses and compared byte for byte with the verified local files. Both downloaded SHA-256 manifests passed.

Installers were built locally, offline, from source/tag `534c1ef7d953c320a7ce0e3948c7eeb8added535`. Intel CLI execution used Rosetta on Apple Silicon with a 60-second process deadline; this does not establish Intel hardware or GUI behavior.

The version-aligned source passed the complete local `cargo xtask check` with
workspace tests/Clippy, frontend tests/type checking/lint/build, release/lab
tooling, isolated RDP/VNC fixtures, package-layout contracts and fuzz compilation.
Coverage includes 107 desktop tests, 42 SSH unit tests, 15 automated authentication cases, five private SDK tests, 22 in-memory SFTP boundary cases, three metadata checks and 14 editor/transfer fault cases. All 25 loopback OpenSSH cases passed in 31.83 seconds. Three manual SSH labs
remain ignored; the real Xvfb check reports its missing-prerequisite skip.
These checks do not establish native GUI acceptance or broader platform behavior.

## Native follow-up and known editor defect — 2026-10-03

A disposable ARM64 release copy passed conflict refusal/reopen recovery,
byte-matched UTF-8 Save, new Save as with mode `0600`, Create only collision
refusal and explicit replacement preserving `0640`. Native menu Quit released
active loopback SSH and the local PTY. These are short lab workflows, not
clean-install or cross-platform acceptance.

**Known defect in these installers:** selecting Windows-1252 and saving fails
before writing because Rust's encoding JSON names do not match the renderer.
The attempted Save preserved the target bytes/mode. The shared wire correction
is on main in `05e80d9`, with its regression, full local check and rebuilt ARM64
native encoding/recovery/Save as workflow passing;
these downloadable files and their tag have not changed.
[Native receipt and remaining gates](https://github.com/OthmaneBlial/MobaRust/blob/main/docs/testing/native-workflow.md#v0125-release-copy-editor-check--2026-10-03).

## Dependency boundary — 2026-10-03

The refreshed RustSec database contains 1,288 advisories at commit
`f8dee89e1b2f2f1eaf548312df7655fe5202a302`. The version-aligned workspace
scan found no vulnerabilities among 638 packages; existing
`RUSTSEC-2024-0370` (unmaintained proc-macro-error) and
`RUSTSEC-2024-0429` (glib unsoundness) warnings remain.

Separate no-fetch scans against the refreshed local database found no
vulnerabilities or warnings in the VNC helper (82 packages) or fuzz lockfile
(52 packages). The excluded RDP candidate (374 packages) still fails on
`RUSTSEC-2023-0071` for rsa 0.10.0-rc.18, with unmaintained warnings
`RUSTSEC-2023-0089` and `RUSTSEC-2025-0134`. This release does not suppress
those findings or enable RDP in normal installers. Only local project version
entries changed in the four lockfiles; third-party versions, sources, checksums
and features remain unchanged.

## Limits

These installers retain the encoding-selector defect; recursive/collision
workflows and broader release-copy SSH acceptance remain pending. The existing walkthrough was
recorded on v0.1.17. Windows/Linux are
not rebuilt by this Mac preview. Mac builds remain ad hoc signed previews without
Developer ID signing or notarization; checksums prove integrity, not publisher
identity. VNC/RDP remain experimental, and the RDP candidate stays excluded from
normal installers. Lost replies, concurrent remote path swaps and dishonest
server metadata remain limits. GitHub workflows remain disabled.
