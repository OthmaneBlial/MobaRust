# MobaRust v0.1.17 — SSH Reliability & Native Tunnel Setup

A macOS desktop preview with quieter SSH sessions, clearer failures, integrated
tunnel forms, and a new walkthrough recorded from the real native app.
Windows/Linux installers remain at v0.1.12; their source improvements are not
newly packaged binaries.

## What changed

- Established SSH sessions no longer close when the connection setup deadline
  expires. Exit status arriving after EOF is preserved.
- Host-trust rejection, unreadable trust files and transport failures remain distinct.
- Local, remote and SOCKS5 forwarding use an integrated form instead of browser
  prompts that did not open in the native macOS runtime. Loopback defaults,
  port validation, cancellation and connection ownership remain explicit.
- The disposable OpenSSH lab now covers transport interruption, server shutdown
  and fresh-connection recovery with unchanged generated trust. This does not
  prove the desktop automatic reconnect loop.
- Windows icon/build and PowerShell/cmd test-fixture fixes are included in source.
- README, roadmap, native workflow evidence and the real desktop demo are refreshed.

## Verification and limits

`cargo xtask check` passed locally. After the focused tunnel UI correction,
frontend type checks, ESLint and unit checks passed, followed by native ARM64
and Intel release rebuilds. Both final DMGs passed disk-image checks when
mounted read-only; their mounted apps passed package layout and strict ad hoc
signature checks. `lipo` confirmed the correct app and bundled VNC-helper
architectures. Both packaged executables returned `MobaRust 0.1.17` for
`--version`, and both SHA-256 manifests passed with `shasum -a 256 -c`.

The [native ARM64 lab receipt](../testing/native-workflow.md) records terminal
input/output, split panes, authenticated SSH, SFTP editing/save, a verified
file download, all three tunnel modes and listener cleanup. The [94-second
walkthrough](desktop-demo.md) documents what was captured and redacted.
These are short controlled tests, not clean-install, Intel GUI or sustained
production interoperability evidence.

The historical [three-platform Quality run](https://github.com/OthmaneBlial/MobaRust/actions/runs/36998538983)
passed on source `ac70e39`. It predates the newest fixture and UI additions.
**Quality and installer workflows remain disabled at the maintainer's request.**
No CI run is claimed for the v0.1.17 tag.

Mac packages are ad hoc signed, not Developer ID signed or notarized. There is
no publisher signing. Checksums confirm byte integrity, not publisher identity.
RDP remains experimental and its helper is excluded from normal packages.

Report bugs with the OS, architecture and reproduction steps in
[GitHub Issues](https://github.com/OthmaneBlial/MobaRust/issues), with private
credentials, host details, paths and logs removed.
