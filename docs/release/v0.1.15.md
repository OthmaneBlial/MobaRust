# MobaRust v0.1.15 — macOS Desktop Preview

This Mac update brings the latest SSH, SFTP, and clipboard fixes to downloadable
installers. Windows and Linux installers remain at v0.1.12 until they can be
built and checked locally on their own operating systems.

## What changed

- Canceling any tunnel port prompt now stops setup. Empty, out-of-range, and
  non-decimal ports are rejected; `0` still requests a free bind port when
  explicitly entered.
- Remote file paths in rename, delete, permission, and transfer-retry prompts
  are quoted. Invisible control characters are escaped in the displayed text;
  the path sent to SSH is unchanged.
- Clipboard actions report success only after the runtime accepts the write.
  When the clipboard API is unavailable, the manual-copy prompt no longer
  produces a false success message.
- Remote desktop clipboard and SSH tunnel labels now refer to the local
  computer instead of assuming a Mac.

## Local verification

`cargo xtask check` passed, including frontend checks, Rust tests, RDP/VNC
loopback fixtures, and fuzz-target compilation. Both DMGs passed
`hdiutil verify`; their mounted apps passed package layout and ad hoc signature
checks. `lipo` confirmed the labeled architecture of each app executable and
bundled VNC helper. Both packaged executables returned `MobaRust 0.1.15` for
`--version`, and both SHA-256 files passed after local collection. These CLI
checks did not open an application window.

These Mac packages have ad hoc code signatures. They are not Developer ID
signed or notarized, so macOS may require its per-app first-launch review.
Checksums detect corruption, not publisher identity. Do not disable system
security globally.

Local builds and fixtures cannot prove a clean installation, sustained GUI
behavior, or real-server interoperability on an Intel Mac. RDP remains
experimental and its helper is excluded from these packages.

Report bugs with the OS, architecture, and reproduction steps in
[GitHub Issues](https://github.com/OthmaneBlial/MobaRust/issues). Remove
credentials, hostnames, IP addresses, and private connection details first.
