# MobaRust v0.1.16 — macOS Desktop Preview

This Mac update prevents a running macro from sending later actions to a
different connection after a selected terminal reconnects or closes. Windows
and Linux installers remain at v0.1.12 until they can be built and checked on
their own operating systems.

## What changed

- A macro pins the native terminal connections selected when the run starts.
  If any selected connection is replaced or closed, later send actions stop
  instead of following a new connection under the same tab.
- This release also includes the tunnel, remote-path confirmation, and
  clipboard fixes from [v0.1.15](v0.1.15.md).

## Local verification

The macro regression test covers target replacement and closure. `cargo xtask
check` passed, including frontend checks, Rust tests, RDP/VNC loopback
fixtures, and fuzz-target compilation. Both DMGs passed `hdiutil verify`;
their mounted apps passed package layout and ad hoc signature checks. `lipo`
confirmed the labeled architecture of each app executable and bundled VNC
helper. Both packaged executables returned `MobaRust 0.1.16` for `--version`,
and both SHA-256 files passed after local collection. These CLI checks did not
open an application window.

These Mac packages have ad hoc code signatures. They are not Developer ID
signed or notarized, so macOS may require its per-app first-launch review.
Checksums detect corruption, not publisher identity. Do not disable system
security globally.

Local builds and fixtures cannot prove a clean installation, sustained GUI
behavior, or real-server interoperability on an Intel Mac. RDP remains
experimental and its helper is excluded from these packages.

Report bugs with the OS, architecture, and reproduction steps in
[GitHub Issues](https://github.com/OthmaneBlial/MobaRust/issues). Remove
credentials, hostnames, IP addresses, and private connection details first.
