# MobaRust v0.1.20 — Concurrent SSH & Terminal Reliability

**Free, open-source MobaXterm alternative built with Rust.** This Mac preview
packages concurrent SSH authentication and terminal lifecycle corrections made
after v0.1.19. Windows/Linux previews remain v0.1.12.

## What changed

- Competing SSH challenges wait in a bounded queue instead of cancelling the
  second login. Each response and cancellation belongs to its original request;
  closing an expired queued request preserves the active dialogue and its input.
- SSH, Telnet and serial startup output is replayed before live output is
  published, avoiding reordered startup text and duplicate replay.
- Terminal output and Close remain observable while an SSH input write waits
  for the peer's receive-window credit. A partial write retains its progress
  across output events rather than restarting its input.
- Closing a shell retires its unread output before awaiting EOF and draining
  transfers. A full shell output queue can no longer hold the SSH actor there
  while other channels need it for cleanup.

## Verification

Release preparation is in progress. Installer verification and publication are
pending; the existing downloads remain v0.1.19.

The version-aligned source passed the complete local `cargo xtask check`,
including 103 desktop tests, workspace tests/Clippy, frontend tests/type/lint/build,
release tooling checks, isolated RDP fixtures, all 17 VNC process cases,
package-layout contracts and fuzz compilation. The refreshed 1,288-advisory
database reports no workspace vulnerability and two warnings; the VNC helper
reports none. No advisory was suppressed.

The source corrections have deterministic production-manager, frontend DOM and
encrypted loopback SSH regressions. Mac debug observations cover two concurrent
reconnects, distinct password/OTP success, cancellation handoff and pending-auth
Quit. Those earlier debug observations are separate from release-copy acceptance.

## Remaining gates

Native queued expiry/overflow, release-copy concurrent authentication and
backpressure acceptance, Windows/Linux runtime coverage, clean installation,
Intel hardware GUI checks and signed distribution remain pending. The latest
queued-expiry UI observation failed; backend/DOM checks do not close that gate.

Mac previews use ad hoc signatures, with no Developer ID signing or notarization.
SHA-256 files establish artifact integrity, not publisher identity. VNC and RDP
remain experimental; RDP is excluded from normal installers because its isolated
dependency audit still reports the RSA timing advisory. The real-app walkthrough
remains the v0.1.17 recording. GitHub workflows remain disabled by request.
