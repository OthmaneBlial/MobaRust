# MobaRust v0.1.26 — Encoding Save Fix & Bounded SFTP

**Free, open-source MobaXterm alternative built with Rust**

This Mac preview fixes the native editor's encoding selector and bounds SFTP directory listings. Windows/Linux downloads remain v0.1.12.

## What changed

- **Encoding Save works:** Rust now shares the frontend's `utf-8` and `windows-1252` wire names. The v0.1.25 argument-decoding defect is fixed for Save and Save as; older wire names remain accepted as input aliases.
- **Bounded directory listings:** the shared browser/recursive-planning reader limits visible entries to 10,000, cumulative decoded text to 16 MiB, and the READDIR phase to 12 seconds. Refusal discards partial listings and awaits directory close. This deadline does not include setup/close or bound whole-process memory; there is no pagination yet.
- **Safer local acceptance lab:** private generated fixture roots and an explicit SFTP start directory prevent accidental account-home listings. This is test infrastructure, not an SSH sandbox or system-service change.

## Limits

The refreshed RustSec database at `83278802b2c75399c153d84a6de246503b62966a` contains 1,289 advisories. The shipping workspace reports no vulnerabilities and retains proc-macro-error/glib warnings; VNC and fuzz report neither vulnerabilities nor warnings. The excluded RDP candidate still fails on `RUSTSEC-2023-0071` and retains two unmaintained warnings; no findings were suppressed. Only local package versions changed in the four lockfiles.

Initial GUI Open expects valid UTF-8; the selector controls output encoding while editing. Explicit legacy-encoding Open, saved-with-warning focus, uncertain promotion recovery, broader native directory-limit acceptance, sustained use and Windows/Linux alignment remain pending. These are ad hoc signed Mac previews without Developer ID/notarization. Checksums establish integrity, not publisher identity. VNC/RDP remain experimental; RDP is absent from normal installers. The walkthrough remains the real v0.1.17 recording. GitHub workflows remain disabled. Historical v0.1.25 files/tags retain their selector defect and are unchanged.
