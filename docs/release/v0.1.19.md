# MobaRust v0.1.19 — Interactive SSH & Safer Transfers

**Free, open-source MobaXterm alternative built with Rust.** This Mac preview
packages the SSH authentication, reconnect and transfer corrections made after
v0.1.18. Windows/Linux previews remain v0.1.12.

## What changed

- Ask-each-challenge SSH authentication supports separate password/OTP prompts
  in Quick connect, saved profiles, jump hops and reconnect. Responses belong to
  one request, are cancelled with that request and are not saved in profiles.
- A narrow local russh packet-reader correction handles peer disconnects while
  an interactive response is pending. RSA remains disabled.
- Successful login and selected-session reconnect return keyboard focus to the
  SSH terminal; a background reconnect preserves the user's active editor/input.
- Closed SSH command queues reject queued file/tunnel operations visibly. A
  reconnect creates a fresh queue without replaying terminal input.
- Transfer cancellation is checked before final promotion. SSH disconnect and
  normal app shutdown drain session-owned transfer workers before completing.
- Terminal labels retain connection errors and distinguish ordinary shell exit
  from a failed transport.

The existing Full-HD VNC renderer is retained. VNC and RDP remain experimental;
RDP is excluded from normal installers because its separate dependency audit
still reports the RSA timing advisory.

## Verification

The version-aligned source passed the complete local `cargo xtask check`:
workspace tests and Clippy, frontend tests/type/lint/build, release-asset tests,
isolated RDP checks and loopback fixtures, all 17 VNC process cases,
package-layout contracts and fuzz compilation. The workspace advisory check
reported no vulnerability and retained two warnings; the VNC helper reported
none. No advisory was suppressed.

Installer verification and download links will be recorded after the matching
artifacts exist. No v0.1.19 release publication or release-copy GUI acceptance
is claimed at this stage.

Existing source and disposable Mac debug receipts cover authentication,
two-bastion routing, reconnect, terminal focus and transfer cleanup:
[SSH lab](../testing/ssh-lab.md), [transfer lifecycle](../testing/transfer-lifecycle.md)
and [queued commands](../testing/queued-ssh-commands.md).
Concurrent native authentication prompts, Windows/Linux acceptance, OpenSSH
password/PAM interoperability, signed distribution and sustained workloads
remain separate gates.

Quality and installer workflows remain disabled by request. Mac previews use
ad hoc signatures; they are not Developer ID signed or notarized. Checksums
verify artifact bytes, not publisher identity. The real-app walkthrough remains
the v0.1.17 recording.
