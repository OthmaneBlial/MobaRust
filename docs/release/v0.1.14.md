# MobaRust v0.1.14 — macOS Desktop Preview

This Mac preview includes terminal-input fixes from `main`. Windows and Linux
installers remain at v0.1.12 until they can be built and checked locally on
their own operating systems.

## What changed

- Confirmed multiline paste now uses xterm's normal paste path, including
  line-ending normalization and bracketed paste when the receiving shell
  enables it. The confirmation warns that some shells can execute pasted lines.
- Broadcast paste is formatted separately for each selected terminal's paste
  mode. Broadcast writes wait for every response before reporting a failure;
  an uncertain or partial delivery remains visible so operators can check
  targets before retrying.
- Terminal error text strips Unicode direction controls that could change how
  a failure appears on screen.
- Traceroute limits each displayed line by UTF-8 bytes, including Unicode
  output.
- Local release collection refuses a folder containing installers from an
  older version, preventing accidental mixed-version uploads.

## Local verification

`cargo xtask check` passed, including frontend checks, Rust tests, RDP/VNC
loopback fixtures, and fuzz-target compilation. Both DMGs passed
`hdiutil verify`; their mounted apps passed package layout and ad hoc signature
checks.
`lipo` confirmed the labeled architecture of each app executable and bundled
VNC helper. Both packaged executables returned `MobaRust 0.1.14` for
`--version`, and both SHA-256 files passed after local collection. These CLI
checks did not open an application window.

These Mac packages have ad hoc code signatures. They are not Developer ID
signed or notarized, so macOS may require its per-app first-launch review.
Checksums detect corruption, not publisher identity. Do not disable system
security globally.

Local builds and fixtures cannot prove a clean installation, sustained GUI
behavior, or real-server interoperability on an Intel Mac. RDP remains
experimental and its helper is excluded from these packages.

Report bugs with the OS, architecture, and reproduction steps in
[GitHub Issues](https://github.com/OthmaneBlial/MobaRust/issues). Remove
credentials, hostnames, IP addresses, and private connection details first.
