# MobaRust v0.1.22 — SSH Streams & Transfer Recovery

**Free, open-source MobaXterm alternative built with Rust.**

This Mac preview packages the latest SSH and file-transfer reliability fixes. Windows/Linux previews remain v0.1.12.

## What changed

- 📁 **Interrupted transfers fail within bounded operation deadlines.** The loopback lab verifies original/partial-file handling during interrupted SFTP/SCP copying and a complete byte-matched retry with 16 MiB files.
- 🔀 **Large terminal output and SFTP can run together through jump hosts.** Pending encrypted writes no longer keep the packet reader from processing inbound traffic. Existing bounded queues and a retained partial-write cursor preserve flow control and ciphertext order.
- 🦀 **Shell exit preserves the final output.** Exit status is delivered after output EOF/close, including stdout and stderr sent after the remote process exited.
- 🧪 **More real OpenSSH evidence.** The lab verifies 8 MiB PTY output plus 8 MiB SFTP upload/download through two distinct IPv6 bastions, with normal and frequent-rekey configurations, per-hop trust rejection and cleanup.

## Validation and limits

Both locally built DMGs passed `hdiutil verify`, mounted package-layout checks and strict ad hoc signature verification. App/helper architectures matched arm64/x86_64, both packaged CLI paths returned `MobaRust 0.1.22`, bundled LICENSE/NOTICE bytes matched the repository, private lab/portable state was absent, and both SHA-256 manifests passed. All owned mounts were detached.

The installers were built locally from source `eeeef962c4616164b56c11c3399891f498398717`. The release tag adds documentation without changing that runtime source or its dependency locks. These package/CLI checks remain separate from native GUI startup and clean-install acceptance.

The version-aligned source passed the complete local `cargo xtask check`: workspace tests and Clippy, frontend tests/type checking/lint/build, release/lab tooling checks, isolated RDP/VNC fixtures, package-layout contracts and fuzz compilation. SSH coverage includes 42 unit tests, 14 automated authentication cases and 16 OpenSSH cases; three manual labs remain ignored and real Xvfb explicitly reports its prerequisite skip.

All SSH fixtures listen only on loopback, with disposable state and generated credentials. Native GUI responsiveness, release-copy SSH acceptance, clean installation/uninstallation and Windows/Linux runtime validation remain separate pending gates. Intel CLI checks use Rosetta on Apple Silicon; they do not establish Intel hardware GUI behavior.

Mac previews have ad hoc signatures without Developer ID signing or notarization. Checksums establish byte integrity, not publisher identity. VNC/RDP remain experimental, and the RDP candidate stays excluded from normal installers because of its known dependency advisory. GitHub workflows remain disabled.
