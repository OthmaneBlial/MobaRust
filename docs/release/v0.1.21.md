# MobaRust v0.1.21 — SSH Startup Safety & Recovery

**Free, open-source MobaXterm alternative built with Rust.** This Mac preview
packages SSH shell setup, startup input and reconnect geometry corrections,
plus explicit startup-command review. Windows/Linux previews remain v0.1.12.

## What changed

- SSH waits for the server to accept shell/X11 setup before sending configured
  startup input. Rejection, closure, excessive setup output and silence fail
  with bounded cleanup instead of returning a successful shell.
- Configured startup input keeps draining output while waiting for receive-window
  credit. A single write preserves partial progress; output is retained in order
  within the existing 1 MiB setup budget and original setup deadline.
- Terminal dimensions survive reconnect backoff independently of the retired
  command queue. Replacement shells use current geometry, and later updates are
  delivered without replaying queued input from the lost connection.
- Saved/imported SSH startup commands require review before connecting. The
  dialogue shows the full command and destination, names automatic reconnect
  repetition, and refuses a stopped macro's pending startup. Saved local startup
  commands share this review helper.
- A disposable Unix SSH setup lab provides secret-free import profiles for
  output pressure, shell rejection and stalled startup input, with generated
  trust and distinct password/OTP factors. Its automated smoke check verifies
  real SSH packets, private metadata, ordered startup echo and owned cleanup.

## Verification

Both locally built DMGs passed `hdiutil verify`. Their read-only mounted apps
passed package-layout and strict ad hoc signature checks. The app and VNC helper
architectures matched arm64/x86_64, both packaged CLI paths returned
`MobaRust 0.1.21`, bundled LICENSE/NOTICE bytes matched the repository, private
lab/portable state was absent, and both SHA-256 manifests passed. All owned
verification mounts were detached.

Intel CLI execution used Rosetta on Apple Silicon. Two initial five-second
version checks timed out; their owned processes were stopped and mounts detached.
A diagnostic run on the same mounted executable completed in 0.832 seconds.
The final freshly mounted Intel package check used a 30-second deadline and
completed in 5.608 seconds. These are version-only diagnostic observations,
not a GUI startup benchmark or evidence of Intel hardware behavior. The cause
of the initial delays was not established.

The installers were built locally from source
`8bb7cf76f2c1bf77c2ab8ba6c579410266e9cb03`, with GitHub workflows disabled.
The release tag adds documentation without changing that runtime source or
its dependency locks. These package/CLI checks are separate from native GUI
startup and clean-install acceptance. Public download verification is pending.

The version-aligned source passed the complete local `cargo xtask check`,
including 104 desktop tests, workspace tests/Clippy, frontend tests/type/lint/build,
release tooling checks, isolated RDP fixtures, all 17 VNC process cases,
package-layout contracts and fuzz compilation. The refreshed 1,288-advisory
database reports no workspace vulnerability and two warnings; the VNC helper
reports none. No advisory was suppressed.

See [SSH setup and reconnect regressions](../testing/ssh-reconnect.md),
[startup review checks](../testing/text-input-dialogs.md) and
[the disposable authentication/setup lab](../testing/ssh-lab.md).

## Remaining gates

Native startup approval, startup output pressure, queued prompt expiry/overflow,
release-copy concurrent authentication, sustained GUI responsiveness, clean
installation/uninstallation and Windows/Linux runtime checks remain pending.
Current native observation failed before any approval or authentication action;
owned app/shell cleanup was verified separately. Build, protocol, DOM and CLI
checks do not establish native GUI acceptance.

Mac previews use ad hoc signatures without Developer ID signing or notarization.
SHA-256 manifests establish artifact integrity, not publisher identity. Intel
hardware GUI evidence remains pending. VNC and RDP remain experimental. RDP is
excluded from normal installers because its isolated dependency audit still
reports the RSA timing advisory. The real-app walkthrough remains the v0.1.17
recording. GitHub workflows stay disabled.
