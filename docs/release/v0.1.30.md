# MobaRust v0.1.30 — Reliable SSH Tunnel Cleanup

**Free, open-source MobaXterm alternative built with Rust**

This Mac preview brings the post-v0.1.29 tunnel lifecycle, operation admission and live-history fixes into downloadable installers. Windows/Linux remain v0.1.12.

## What changed

- **Stop explicit remote forwards correctly:** when a server accepts a requested nonzero port without echoing it, the app keeps the actual port for display and cancellation. SDK and disposable OpenSSH checks verify Stop releases the listener before disconnect.
- **Retire uncertain forwarding attempts:** if a polled remote-forward approval or revocation is dropped, times out or cannot be confirmed, the owned SSH transport closes. This also ends other work on that connection; reconnect after checking the remote service. Explicit approval refusal and a confirmed normal Stop preserve the connection. A noncompliant server may retain a listener outside its SSH connection lifecycle.
- **Bound accepted work:** finite file/monitor, transfer and tunnel jobs share a 32-worker owner per SSH session. A full 64-command queue refuses these starts promptly. Session cleanup cancels and joins accepted tunnel runners. These limits do not bound total IPC or process memory across many sessions.
- **Keep live controls visible:** active tunnel and transfer rows remain in history with Stop/Cancel controls. Only finished history is capped at 20 tunnels and 40 transfers.

## Limits

Native v0.1.30 Stop/Close/Quit, saturation/Retry, live lists above the old history limits, keyboard/focus and sustained traffic acceptance remain pending. The latest native candidate could not be inspected because macOS window access was unavailable; it was cleaned up without starting an SSH fixture. Earlier v0.1.29 startup and v0.1.27 editor receipts retain their original artifact scope and are not v0.1.30 GUI evidence. Wider servers, clean installation/uninstallation, Intel hardware/GUI and Windows/Linux alignment remain open.

RustSec database `ef6173cbc5c50ec8166f9a5b28f07834144373ee` (1,290 advisories) reports no vulnerabilities in the shipping workspace, VNC helper or fuzz lockfile. Workspace proc-macro-error/glib warnings remain. The excluded RDP candidate still fails on `RUSTSEC-2023-0071` and retains two unmaintained warnings; no findings were suppressed. Only 15 local package version entries changed across four lockfiles; third-party packages did not change.

These are ad hoc signed Mac previews without Developer ID/notarization. Checksums establish integrity, not publisher identity. VNC/RDP remain experimental; RDP is absent from normal installers. The real walkthrough remains the v0.1.17 recording. GitHub workflows remain disabled. Historical releases and tags are unchanged. The roadmap remains 57 of 76 checked items (75%); this is checklist completion, not production readiness.

Protocol tests use disposable HOME/state and loopback listeners only. They do not enable Remote Login, alter firewall/router rules, inspect personal SSH configuration or expose a home-network port.
