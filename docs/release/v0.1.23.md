# MobaRust v0.1.23 — SFTP Bounds & Session Cleanup

**Free, open-source MobaXterm alternative built with Rust.**

This Mac preview improves failed SFTP setup, remote-response handling and accepted file-operation cleanup. Windows/Linux previews remain v0.1.12.

## What changed

- 🛡️ **Bound SFTP responses before allocation.** Both file and directory-listing channels enforce the configured response payload limit (256 KiB by default), reject impossible sequence counts and DATA longer than requested, and settle pending requests when invalid frames or EOF close their stream. Failed channels leave the SSH transport usable.
- 📁 **Require SFTP subsystem acceptance.** Both channel paths wait for the server's acceptance before INIT. Refusal, early closure, silence and cancellation have bounded setup and owned channel cleanup.
- 💾 **Await accepted file operations during session cleanup.** Editor Save/Save as, file mutations, directory listing, opening text and monitor collection join session-owned workers. Their existing operation deadlines cover completion and rollback before SSH disconnect; queued commands remain subject to retirement.
- 🧪 **Improve private X11 fixture diagnostics.** Setup failures report only xauth stages from disposable state. An intermittent five-second fixture failure remains unexplained; this is diagnostic coverage, not an X11 runtime fix.

## Validation and limits

All four published files were downloaded anonymously over HTTPS with HTTP 200 responses and compared byte for byte with the verified local files. Both downloaded SHA-256 manifests passed.

Both locally built DMGs passed `hdiutil verify`, read-only mounted layout checks and strict ad hoc signature verification. App/helper architectures match arm64/x86_64. Both packaged CLI paths returned `MobaRust 0.1.23` with disposable HOME and no SSH agent. Bundled LICENSE/NOTICE bytes match the repository; private lab/portable state is absent. Both manifests passed and all owned mounts were detached.

Installers were built locally, offline, from source/tag `b36bc784251b5bdc159e6ea6507e43b9df63ec74`. The version-aligned source passed the complete local `cargo xtask check`: workspace tests/Clippy, frontend tests/type checking/lint/build, release/lab tooling, isolated RDP/VNC fixtures, package-layout contracts and fuzz compilation. Coverage includes 105 desktop tests, 42 SSH unit tests, 15 automated authentication cases, five in-memory SFTP boundary cases and 16 OpenSSH cases. Three manual labs remain ignored; real Xvfb reports its missing-prerequisite skip. The final X11 bridge case passed, but its earlier intermittent failure's cause is still unproven.

SSH fixtures use loopback-only listeners, disposable state and generated credentials. Package/CLI checks do not establish native GUI startup, editor save/exit acceptance, sustained responsiveness, clean install/uninstall or Windows/Linux runtime behavior. Intel CLI checks use Rosetta on Apple Silicon, not Intel hardware.

Mac previews have ad hoc signatures without Developer ID signing or notarization. Checksums establish byte integrity, not publisher identity. VNC/RDP remain experimental; the RDP candidate is excluded from normal installers because of its known dependency advisory. GitHub workflows remain disabled.
