# MobaRust v0.1.18 — Native Dialogs & Full-HD VNC

**Free, open-source MobaXterm alternative built with Rust.** This macOS preview
packages the native dialogue, reconnect-safety and renderer improvements made
after v0.1.17. Windows/Linux installers remain v0.1.12.

## What changed

- Text entry and confirmations use integrated app dialogues, including multiline
  JSON, file collision choices and cancellation, instead of browser prompts.
- Paste, macro approvals, file operations and editor documents remain bound to
  their original SSH connection generation; stale approvals fail closed.
- Emergency broadcast/macro stops run before terminal or modal event propagation.
- Settings failures remain visible inside the form and receive keyboard focus;
  rejected settings do not replace persisted preferences.
- Full-HD VNC uses bounded binary frames through both the helper pipe and Tauri
  IPC. A latest-frame pull coalesces notifications and rejects stale reconnect
  replies. The 8 MiB frame limit remains; this is not an FPS or latency claim.
- Tauri 2.12.1 restores macOS element fullscreen. The Rust minimum is now 1.90.
  VNC and RDP remain experimental; RDP is excluded from normal installers.

## Verification and limits

The version-aligned source passed the complete local `cargo xtask check`:
Rust workspace tests/Clippy, frontend tests/type/lint/build, release-asset checks,
isolated RDP checks, 17 VNC process cases, package layouts and fuzz compilation.
The cached workspace advisory audit reported no vulnerability and retained two
transitive warnings; the RDP helper still has a separate security gate.

Both locally built DMGs passed `hdiutil verify`. Read-only mounted apps passed
package-layout and strict ad hoc signature checks. App and bundled VNC-helper
architectures matched arm64/x86_64; both packaged CLI versions returned
`MobaRust 0.1.18`. Both SHA-256 manifests passed. Intel CLI startup used Rosetta
on Apple Silicon; no Intel hardware GUI session is claimed.

A disposable portable copy of the ARM64 app from the verified DMG displayed
1920×1080 VNC fixture pixels and accepted keyboard input before and after a
controlled reconnect. A shortcut collision produced a focused error inside
Settings and left persisted settings byte-identical. Native menu Quit exited
successfully and released the active zsh PTY and VNC helper. The fixture bound
only `127.0.0.1`; owned processes were stopped and its port was closed afterwards.

Release fullscreen entry produced the WebKit fullscreen accessibility surface
and Exit fullscreen button. UI automation switched back to the original window,
so this release check does not establish fullscreen keyboard/button/Escape
acceptance; the earlier isolated debug receipt records those observations.
Clean installation, external-server interoperability and sustained rendering
measurements remain pending. Detailed receipts are in
[the renderer guide](https://github.com/OthmaneBlial/MobaRust/blob/main/docs/testing/remote-desktop-renderer.md)
and [native dialogue checks](https://github.com/OthmaneBlial/MobaRust/blob/main/docs/testing/text-input-dialogs.md).

**Quality and installer workflows remain disabled by request.** No tag CI run
is claimed. Mac packages are ad hoc signed, not Developer ID signed or notarized.
Checksums verify bytes, not publisher identity.
