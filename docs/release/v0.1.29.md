# MobaRust v0.1.29 — Stop Retries After Uncertain SSH Startup

**Free, open-source MobaXterm alternative built with Rust**

This Mac preview stops automatic reconnect retries after uncertain startup-input delivery. Windows/Linux downloads remain v0.1.12.

## What changed

- **Stop at an uncertain startup attempt:** if startup input times out or fails after the shell has opened, automatic reconnect stops at that attempt. Some input may already have reached the server; check the remote session and startup settings before reconnecting.
- **Keep ordinary recovery:** failures before startup input retain bounded retries. Success and explicit cancellation retain their existing paths.
- **Keep diagnostics private:** displayed startup errors include no configured commands, credentials or raw server text. The underlying failure stays typed.

Startup commands can still run again after a later approved reconnect. This change does not guarantee exactly-once execution across connection loss.
