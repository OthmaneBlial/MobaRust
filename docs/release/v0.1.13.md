# MobaRust v0.1.13 — macOS Desktop Preview

This preview updates the Apple Silicon and Intel Mac installers. Windows and
Linux installers remain at v0.1.12 while their next builds await local native
validation.

## What's improved

- SSH connection timeouts, reconnect limits, jump-host aliases, and tunnel
  channel timeouts follow the saved configuration more reliably.
- SFTP preserves literal and whitespace-sensitive paths, keeps root navigation
  absolute, and allows uploads when overwrite is disabled.
- OpenSSH and JSON imports preserve existing profiles and report skipped
  entries. One invalid OpenSSH host no longer discards valid neighbors.
- Network diagnostics apply saved defaults, honor early cancellation, and
  ignore stale responses.
- Remote text replacement preserves Unicode characters.
- All five local data stores reject broken symbolic-link paths instead of
  treating them as empty stores.

SHA-256 files are attached beside both DMGs. Windows and Linux users can use
the [v0.1.12 preview](https://github.com/OthmaneBlial/MobaRust/releases/tag/v0.1.12).

These Mac packages have ad hoc code signatures. They are not Developer ID
signed or notarized, so macOS may require its per-app first-launch review.
Checksums detect corruption, not publisher identity. Do not disable system
security globally.

Both DMGs were built locally, checked for disk-image integrity, inspected for
the matching app and VNC-helper architecture, and verified for package layout,
code signature, and `mobarust --version` startup. These checks do not prove a
clean install, sustained GUI use, or real-server interoperability on an Intel
Mac. RDP remains experimental and its helper is excluded from these packages.

Report bugs with the OS, architecture, and reproduction steps in
[GitHub Issues](https://github.com/OthmaneBlial/MobaRust/issues). Remove
credentials, hostnames, IP addresses, and private connection details first.
