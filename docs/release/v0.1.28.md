# MobaRust v0.1.28 — Readable SSH Startup Review

**Free, open-source MobaXterm alternative built with Rust**

This Mac preview keeps long startup-command reviews readable and makes stalled startup input easier to diagnose. Windows/Linux downloads remain v0.1.12.

## What changed

- **Review long commands clearly:** the full command has its own keyboard-scrollable region; the destination, automatic-reconnect warning and Cancel/Continue controls remain visible. Cancel stays the initial focus.
- **Recognize a startup-input timeout:** after authentication and shell acceptance, stalled startup input reports its specific phase and advises checking the remote session and startup settings before reconnecting. The message includes no configured command, credentials or destination.
- **Keep the existing safeguards:** deadlines, output draining, channel cleanup and startup approval remain unchanged. Earlier remote-editor encoding and file-protection changes remain included.
