# MobaRust v0.2.0 — Terminal-first workspace, MobaXterm import, one-click groups

**Free, open-source MobaXterm alternative built with Rust.**

## What changed since v0.1.31

- **The terminal gets the window.** Resizable or collapsible sidebar (⇧⌘B), focus mode, a tab menu and reliable tab closing.
- **Bring your MobaXterm sessions.** Import `.mxtsessions`, `.moba` and `MobaXterm.ini` files exported on Windows, on any OS (Windows-1252, UTF-8, UTF-16, CRLF). SSH and SFTP bookmarks keep their folders, host, port, user, login command, SSH gateways and key file names. Passwords and credential sections are never read. A preview lets you add, replace or skip duplicates, then one atomic write saves them.
- **Open a whole group in one click.** Nested folders, open all or only selected hosts, four connections at a time with a status light per host, cancel and retry, pinned groups, opt-in tab restore and `mobarust --open-group "Folder/Sub"`.
- **Trust imported hosts explicitly.** MobaXterm's known host keys are not imported, so a first connection refuses an unknown key. After a group open, **Trust host keys…** shows each observed fingerprint with the sessions it covers; accept it only after checking it on the server (for example `ssh-keygen -lf`), and it is pinned to those sessions. Startup command reviews for a group appear one after another.
- **Tabs you can name and order.** Rename a tab from its menu (the name stays), move tabs with ⌃⇧PageUp/PageDown, and turn on copy on select in terminal settings.
- **Instrument Panel redesign.** New tokens, dark and light themes, status lamps, group hues, visible focus and a contrast pass (4.5:1 minimum).
- **Faster with large session lists.** Memoized, virtualized session tree and deferred search.
- **New brand and website.** Original mark and icons, rewritten README, and a new site at https://othmaneblial.github.io/MobaRust/.

Each platform has a SHA-256 checksum file. Verify macOS with `shasum -a 256 -c SHA256SUMS-macos-arm64.txt`, Linux with `sha256sum -c SHA256SUMS-linux-x64.txt`, or compare Windows `Get-FileHash` output against `SHA256SUMS-windows-x64.txt`. Checksums detect corruption; they are not publisher signatures.

## How it was checked

- Native macOS (Apple Silicon) release build, driven with real mouse and keyboard in an isolated copy: local shell, MobaXterm import through the file picker, a 14-host group against a local OpenSSH server (14/14 connected after trusting its key, each running its login command), tab rename and move, copy on select, pins and tab restore across a relaunch, and quit.
- Real local OpenSSH: 14 concurrent SSH sessions connected in 558 ms; an imported Windows export connects through its gateway.
- The release workflow builds every installer on native GitHub runners and checks version, asset names, checksums and binary startup. Windows, Linux and Intel Mac builds were not run by hand.

## Preview limitations

These unsigned installers may trigger operating-system security prompts. Windows may show SmartScreen. macOS may block first launch because the app is not Developer ID signed or notarized. If you choose to proceed, use the operating system's app-specific review flow; do not disable system security globally.

RDP is experimental and its helper is excluded from these packages. VNC is experimental; remote TCP is unencrypted and requires explicit opt-in. This preview is not a production-readiness claim.

Report issues with your OS, architecture, and reproduction steps at <https://github.com/OthmaneBlial/MobaRust/issues>. Do not include credentials or private host details.
