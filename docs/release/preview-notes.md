# MobaRust v0.1.12 — Desktop Preview

These are the historical v0.1.12 notes, still relevant to the Windows/Linux
downloads. For current Mac installers, use the [v0.1.19 preview](v0.1.19.md).

This patch release hardens SFTP filenames and metadata, improves network diagnostic results, and closes a terminal resize callback during teardown.

## What's new

- SFTP listings reject unsafe and replacement-decoded names before constructing action paths. Recursive uploads reject local filenames that cannot be represented as UTF-8 instead of silently changing them.
- Remote entries preserve an absent file size as unknown. Listings no longer show false `0 B` values, and recursive download progress does not invent a total when sizes are missing or overflow.
- TCP diagnostics distinguish a refused connection, a timeout, and other immediate failures.
- Closing a terminal cancels its scheduled first-fit animation frame.

The current SFTP library decodes invalid UTF-8 with the replacement character. MobaRust fails closed on names containing that character because the original bytes cannot be distinguished from a literal replacement character after decoding.

Each platform has a SHA-256 checksum file. Verify macOS with `shasum -a 256 -c SHA256SUMS-macos-arm64.txt`, Linux with `sha256sum -c SHA256SUMS-linux-x64.txt`, or compare Windows `Get-FileHash` output against `SHA256SUMS-windows-x64.txt`. Checksums detect corruption; they are not publisher signatures.

## Preview limitations

These unsigned installers may trigger operating-system security prompts. Windows may show SmartScreen. macOS may block first launch because the app is not Developer ID signed or notarized. If you choose to proceed, use the operating system's app-specific review flow; do not disable system security globally.

Start with a local terminal, or add an SSH host, username, and authentication method. Verify the host-key fingerprint before accepting a first connection. SSH, SFTP/SCP, saved sessions, and tunnels are the main use cases. RDP is experimental and its helper is excluded from these packages. VNC is experimental; remote TCP is unencrypted and requires explicit opt-in.

The v0.1.12 release workflow built installers on native GitHub runners and checked version, asset names, checksums, and binary startup. Quality and installer workflows are now disabled by request; newer Mac previews are built and checked locally. A successful build is not evidence of full GUI clean-install behavior or real-server interoperability across all platforms. This preview is not a production-readiness claim.

Report issues with your OS, architecture, and reproduction steps at <https://github.com/OthmaneBlial/MobaRust/issues>. Do not include credentials or private host details.
