# MobaRust v0.1.3 — Desktop Preview

MobaRust is a free, open-source native desktop workspace for SSH, SFTP/SCP, local terminals, tunnels, and operator tools. This unsigned preview focuses on reliable recovery and safer input handling since v0.1.2.

## What's new

- Macro recordings now keep a recoverable draft when the 64-action limit is reached. Empty macros cannot be saved, and the editor enforces the same limit.
- Repeated or concurrent SSH disconnects are safe. Jump-host cleanup continues if the target connection fails to close.
- Telnet host values now reject leading or trailing whitespace, control characters, and inputs longer than 255 bytes before network lookup.
- The documentation page keeps its tables usable on narrow screens.

## Preview limitations

These unsigned installers may trigger operating-system security prompts. Windows may show SmartScreen. macOS may block first launch because the app is not Developer ID signed or notarized. If you choose to proceed, use the operating system's app-specific review flow; do not disable system security globally.

Start with a local terminal, or add an SSH host, username, and authentication method. Verify the host-key fingerprint before accepting a first connection. SSH, SFTP/SCP, saved sessions, and tunnels are the main use cases. RDP is experimental and its helper is excluded from these packages. VNC is experimental; remote TCP is unencrypted and requires explicit opt-in.

The release workflow builds installers on native GitHub runners and checks binary startup. A successful build is not evidence of full GUI clean-install behavior or real-server interoperability across all platforms. This preview is not a production-readiness claim.

Report issues with your OS, architecture, and reproduction steps at <https://github.com/OthmaneBlial/MobaRust/issues>. Do not include credentials or private host details.
