# MobaRust v0.1.2 — Desktop Preview

MobaRust is a free and open-source native desktop workspace for SSH, SFTP/SCP, local terminals, tunnels, and operator tools. This unsigned preview brings reliability and safety fixes since v0.1.1.

## What's new

- UTF-8 output now survives split reads across SSH, Telnet, serial, and local terminal streams.
- SFTP and SCP transfers handle overwrite more carefully, preserve remote permissions, and guard recursive transfers against symlink and special-file paths.
- Telnet now answers terminal-type requests and avoids redundant negotiation traffic.
- OpenSSH config import handles quoted and equals-delimited options more reliably.
- Terminal listeners, tab keyboard controls, session-bound file editing, and error reporting are more robust.

## Preview limitations

These unsigned installers may trigger operating-system security prompts. Windows may show SmartScreen. macOS may block the first launch because the app is not Developer ID signed or notarized. If you choose to proceed, use the operating system's app-specific review flow; do not disable system security globally.

Start with a local terminal, or add an SSH host, username, and authentication method. Verify the host-key fingerprint before accepting a first connection. SSH, SFTP/SCP, saved sessions, and tunnels are the main use cases. RDP is experimental and its helper is excluded from these packages. VNC is experimental; remote TCP is unencrypted and requires explicit opt-in.

The release workflow builds installers on native GitHub runners and checks binary startup. A successful build is not evidence of full GUI clean-install behavior or real-server interoperability across all platforms. This preview is not a production-readiness claim.

Report issues with your OS, architecture, and reproduction steps at https://github.com/OthmaneBlial/MobaRust/issues. Do not include credentials or private host details.
