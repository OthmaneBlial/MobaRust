# X11 forwarding research boundary

MobaRust does not claim to ship an integrated X server in the local terminal slice.

## Options to evaluate

1. SSH X11 forwarding to an external X server.
2. A bundled X server on Windows with its own packaging, licensing, update, and security review.
3. A native helper process with an explicit display/socket bridge.

Windows would need a separately maintained X server component; Linux behavior depends on X11/Wayland and the user's desktop bridge; macOS generally relies on an external XQuartz installation. Each option changes the trust boundary and must not be hidden behind an `X11 enabled` checkbox.

## Release rule

The SSH protocol adapter may expose forwarding only after the display target and security implications are explicit. Integrated X11 is a separate research and packaging project, not a consequence of accepting an SSH `-X` setting.
